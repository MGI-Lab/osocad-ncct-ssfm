# Code and data availability

## Code

The repository URL is <https://github.com/MGI-Lab/osocad-ncct-ssfm>.
The code, packaged classifier checkpoint, approved aggregate statistics, and
publication figures are available in this repository.
Code Ocean is not used.

A submission statement should identify the released version or commit as well
as the repository. Add a version DOI only after the corresponding archive exists.
Do not describe the whole clinical pipeline as reproduced merely because the
code and final figures are accessible; see [Reproducibility](REPRODUCIBILITY.md).

## Study data

The public package contains aggregate results and approved figures. It does not
provide patient-level images, clinical records, labels, prediction workbooks,
or identifiers. Technical access to a local file is not permission to publish it.

Before submitting a final Data Availability statement, the authors and the
responsible institutions need to confirm:

- which study data can be shared and with whom;
- the reason for any restriction and the approval process;
- the named contact and a realistic response timeframe;
- any data-use agreement, secure transfer requirement, or reuse restriction.

Those institutional terms are not established by this code update. This document
does not promise unrestricted access, automatic approval, or access "on reasonable
request" without a working process behind that phrase. Editors should be told
about restrictions when the manuscript is submitted.

## Licenses and third-party assets

The maintainers must confirm licensing for the project code, model weights, and
any third-party pretrained backbone separately. No MIT, Apache, or other license
has been assigned by this synchronization. Public visibility is not a substitute
for permission to redistribute third-party assets.

See the [Nature Medicine reporting and availability policy](https://www.nature.com/nm/editorial-policies/reporting-standards)
for code review, controlled-data access, and version-archive expectations.
